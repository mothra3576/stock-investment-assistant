# 銘柄データ形式 v1

ブラウザ内で完結する取込用形式です。実データの正確性・適時性・利用権は利用者が確認してください。外部送信は行いません。形式を検証しても財務内容の正しさは保証できません。

## 形式と制限

- UTF-8のCSVまたはJSON。最大2MB、1〜2,000行、365〜366日の通期のみ。四半期・変則決算は未対応。
- JSONは下記全項目を持つ行オブジェクトの配列。CSVは同じ名前の全列ヘッダーを指定（順不同）。未知の列・欠落列を拒否。
- 1行＝1銘柄の1会計期間・実績／予想区分。複数期は別行で記載。
- CSVはRFC 4180の引用符・カンマ・引用符内改行・CRLF・BOMに対応。数値の桁区切りや「円」「%」は不可。JSON数値文字列も不可。
- 数値欠損はJSONで`null`、CSVで空欄。0は0として保存。NaN・Infinity・絶対値1e16超を拒否。
- 全行を検証後、一括で現在の取込データを置換。1行でも異常なら保存しない。元の取込データは維持。
- 取込データとファイル名・取込日時はIndexedDBに保存し、再読み込み後も復元。サンプルに戻す操作は取込データを削除。
- サンプル見本はすべて架空。実在企業の数値ではない。

## 項目

| 項目                                  | 型・意味                                                                                                              |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| market                                | `JP` または `US`                                                                                                      |
| code                                  | 英数字・`.`・`-`、1〜12文字。大文字に正規化。市場との組で識別                                                         |
| name / sector                         | 企業名／業種（1〜160文字／1〜80文字）                                                                                 |
| currency                              | JPは`JPY`、USは`USD`。比較表では通貨を列ごとに表示                                                                    |
| amountUnit                            | 常に`unit`。金額は円／USDの実額。百万円・億円に換算して入力しない                                                     |
| price                                 | 株価（円／USD）、正数または欠損                                                                                       |
| priceDate                             | 株価・時価総額の基準日、YYYY-MM-DD                                                                                    |
| marketCap                             | 基準日の時価総額。円／USDの実額、非負数または欠損                                                                     |
| quoteSource                           | 株価・時価総額の出典（1〜500文字）。参考URLも文字列で記入可能                                                         |
| updatedAt                             | 元データの更新日（取込日とは別）、YYYY-MM-DD。基準日・実績期末日以降                                                  |
| periodStart / periodEnd               | 会計期間の開始日／終了日、YYYY-MM-DD、両端を含め365〜366日                                                            |
| basis                                 | `actual`＝実績、`forecast`＝予想                                                                                      |
| standard                              | 会計基準名。例：日本基準、IFRS（1〜80文字）                                                                           |
| scope                                 | `consolidated`＝連結、`standalone`＝単体                                                                              |
| financialSource                       | 財務値の出典・資料名・取得箇所など（1〜500文字）                                                                      |
| revenue / operatingProfit / netIncome | 当該通期の売上高／営業利益／純利益。連結の純利益は親会社所有者（株主）に帰属する利益、単体は当期純利益。円／USDの実額 |
| averageEquity                         | 当該通期の平均自己資本（ROE用）。非負数または欠損。期末自己資本で代用しない                                           |
| equity / totalAssets                  | 当該期末の自己資本／総資産。円／USDの実額。総資産は非負数または欠損                                                   |
| eps / bps / dividendPerShare          | 当該通期の1株利益／期末1株純資産／年間1株配当（円／USD）。配当は非負数または欠損                                      |

同じ市場・証券コードの全行では、企業名・業種・株価・時価総額・基準日・更新日・通貨・株価出典を一致させてください。同一銘柄・区分内で会計期間が重複する行は、会計基準・連結区分が異なる場合も拒否します。比較する会計基準をあらかじめ選んで取り込んでください。予想と実績が同じ期間であることは許容します。

## 指標・比較のルール

一覧は市場・通貨を選び、全数値条件をANDで適用。上下限の端を含み、下限>上限は0件。範囲を指定した指標が欠損なら除外し、未指定なら含めます。ソートの欠損は昇降順とも最後。範囲条件の時価総額の単位は億円／億USD、ROE・配当利回り・成長率・利益率・自己資本比率は%です。

財務は選択した実績／予想区分の最新期を使用。該当区分がなくても価格と時価総額は表示します。財務由来の指標は欠損になります。

- PER＝基準日の株価÷EPS、PBR＝基準日の株価÷BPS。EPS/BPSが0以下なら算出不可。
- ROE＝純利益÷平均自己資本×100。平均自己資本が0以下なら算出不可。
- 配当利回り＝年間1株配当÷基準日の株価×100。
- 売上高成長率＝(当期売上÷前期売上−1)×100。実績／予想・会計基準・連結区分が同一で、直前の通期の終了翌日が当期の開始日である場合だけ算出。前期売上0・欠損なら算出不可。
- 営業利益率＝営業利益÷売上高×100。売上高0なら算出不可。
- 自己資本比率＝期末自己資本÷期末総資産×100。総資産0なら算出不可。
- 時価総額は入力元の株価基準日の値。自己株式の取り扱い等は出典の定義を確認。

株価の日付と財務期間は別々に明示します。年率換算・為替換算・株式分割補正・異なる会計基準の組み替えはしません。EPSなどの調整方法は出典で確認してください。グラフは選択期と同じ区分・基準・連結区分だけを描画し、欠損を0として結びません。最大5銘柄の比較表には各列の期間・通貨・出典を表示し、高低による優劣判定はしません。

## 保存と同期

`StockDataProvider`が取得、`AnalysisRepository`がIndexedDB永続化を担当します。銘柄分析用DBは`stock-investment-analysis` v1（`watch`・`datasets`）で、従来の学習DBは変更しません。ウォッチは市場・コード・登録名・登録日時を保存し、銘柄データを入れ替えても登録は維持します。新しいデータセットにない銘柄は「現在のデータセットにはありません」と表示して削除可能です。同じ市場・コードを再利用した別の取込データではそのコードを同一銘柄として扱うため、コードの一貫性を保ってください。

将来のOneDrive同期では、この保存インターフェースにアダプタを追加し、認証・権限・競合・削除の扱い・形式移行を別途実装します。今回は同期・外部API・自動更新・通知・売買は実装していません。

自己資本・平均自己資本は純利益と同じ帰属範囲で入力してください。連結では非支配持分等を含む純資産合計を自己資本で代用しないでください。会計基準による定義差は出典に記載し、入力元で整合させてください。
